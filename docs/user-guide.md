# 销售工作台 · 同事使用指南

本指南供公司同事试点使用。工作台入口：[https://sales.omfreight.vip](https://sales.omfreight.vip)。请使用本人账号记录客户和沟通情况。

## 进入工作台

1. 打开 [销售工作台](https://sales.omfreight.vip)。试点员工的用户名为本人姓名，以管理员私下发给本人的账号信息为准。
2. 在“账号”中填写用户名，在“密码”中填写本人临时密码，点击“登录工作台”。每人使用独立临时密码，不与同事共用账号。
3. 首次登录必须修改密码：在“当前密码”中填写临时密码，设置至少 14 位的新密码并再次确认，然后点击“保存新密码”。新密码应与临时密码不同。
4. 修改成功后，用原用户名和新密码重新登录，即可进入工作台。管理员重置密码后，也需要按此步骤设置新密码。

账号和临时密码由管理员私下逐一发放给本人。未收到账号或忘记密码，请联系本组管理员；不要在群聊中发送密码。登录有效期为 8 小时，日常改密可从右上角头像菜单进入“修改密码”。离开公共电脑前，先保存正在填写的内容，再选择头像菜单中的“退出登录”。

默认显示“我的客户与记录”。数据范围栏会显示本人所在团队。主管可切换“本团队”，管理员可切换“全公司”及指定团队/负责人；切换范围前先保存或关闭正在填写的内容。

## 每天的工作顺序

1. 查看“待跟进客户”，优先处理逾期项目。
2. 拨打电话或完成拜访后，进入“电销·扫楼”记录沟通结果。
3. 成功添加联系方式后可以立即转客户，也可以稍后在“电销记录”里继续。
4. 打开客户详情，记录报价、询价和下单等跟进内容，并设置下一次跟进日期。

系统仅记录实际沟通，不自动拨号，不录音，不向客户自动发消息。

## 建立和维护客户

点击“新增客户”，填写客户名称和手机号码，再补充联系人、来源、地址和业务需求。当前主要联系电话使用大陆 11 位手机号，备用电话可填座机等信息。相同手机会提示已有客户，请核对；系统允许有正当原因的重复档案。

新客户默认“已添加”。确认完成开户后改为“已开户”，实际走货后改为“已走货”。普通销售只能逐级前进；错误状态由主管或管理员填写原因回退。下单跟进会询问是否同时升级，也可选择“仅记录跟进”。

“开户客户”统计包含已经走货的客户；“客户状态分布”按当前阶段分组。走货票数需要另外接入业务数据，目前显示“待接入”，不等同于已走货客户数量。

跟进安排分为保持原安排、设置日期、取消安排。日期按上海时间当天上午 10:00 保存。详情时间线保留历史记录，无法直接覆盖旧跟进。

归档会隐藏普通列表中的客户并保留历史。主管或管理员可查看归档客户并恢复。恢复会沿用原提醒日期，可能立即显示逾期。负责人交接由主管或管理员填写原因操作。

## 电销、扫楼与转客户

电销需要手机；扫楼需要地址，暂时没有电话也能先记拜访。沟通结果会建议下次判断，仍可自行调整。

只有“成功添加联系方式”的记录可以转客户。进入建档页后可选择新建，或搜索并关联已有客户。取消建档不算已转客户；只有保存成功才会出现“已转客户”。关联已有客户不会覆盖其资料。

当前数据范围内的历史电销和扫楼记录都在“电销记录”页面，可按类型、结果、下次判断和关键字筛选。录入错误由管理员更正并留原因；已经转化的记录不会反向覆盖客户资料。

## 遇到问题

- 提示“资料已发生变化”：他人已修改同一资料，当前输入仍保留。点击“查看最新资料（保留当前输入）”；在客户跟进处点击“查看最新客户资料”。核对最新内容后再保存。
- 网络错误：保留当前表单，恢复连接后重试。不要连续切换页面重新录入同一件事；刷新或关闭页面不会恢复尚未保存的输入。
- 无法看到客户：检查当前数据范围，联系主管核对负责人或团队。
- 忘记密码或无法登录：联系本组管理员核对账号状态或重置密码。收到本人新的临时密码后，登录并设置新密码，再重新登录。
- 界面报错：把报错提示与请求编号发给管理员，避免在群聊传播客户手机、密码和完整客户截图。

## 管理员

先建立团队，再添加销售/主管账号。停用或调组前查看影响预览；客户和历史活动按员工当前团队归属统计。团队中仍有启用员工时不能停用团队，系统始终保留至少一位启用管理员。

试点员工用户名使用本人姓名，确认账号与本人对应。新增或重置员工后，临时密码仅展示一次；每人使用独立临时密码，由管理员通过公司认可的渠道私下发给本人。发放内容包括工作台入口、本人用户名、本人临时密码及首次登录改密说明。员工名单和密码不要放入公共文档或群聊。临时密码遗失时重新重置，员工首次使用或重置后必须改密。“操作审计”可按对象和操作类型检索变更记录。
